# 임승혁

기후 리스크 분석 스타트업에서 백엔드 개발을 맡고 있습니다. 이 계정에는 개인 프로젝트를 올립니다.

### 프로젝트
- **Relivio** — 배포 직후 오류와 지표를 모아 새 버전이 정상인지 판정하는 서비스  
  [Python SDK](https://github.com/lazypl82/relivio-sdk-python) · [TypeScript SDK](https://github.com/lazypl82/relivio-sdk-typescript) · [GitHub Action](https://github.com/lazypl82/deploy-monitor-action) · [MCP 서버](https://github.com/lazypl82/relivio-mcp)
- **[contextctl](https://github.com/TEAM-SEAM-contextctl/contextctl)** — AI가 승인된 문서만 검색하도록 범위를 제한하는 문서 검색 도구(CLI·MCP), 3인 팀 프로젝트
